Sobre mí

Backend sólido, código limpio y resultados medibles para el negocio.

Soy Desarrollador de Software Senior con más de 7 años de experiencia construyendo soluciones backend con Java y Spring Boot para empresas de banca, telecomunicaciones, logística de valores y retail.

Mi especialidad es la migración de sistemas monolíticos a arquitecturas de microservicios, con foco en rendimiento, escalabilidad y mantenibilidad. Trabajo en entornos cloud con Azure y on-premise, y automatizo despliegues con flujos CI/CD usando Jenkins y Docker.

También tengo experiencia en el frontend con JavaScript y Vue.js, y he liderado técnicamente módulos completos: desde el refinamiento de requisitos con negocio hasta el diseño de la solución y el desarrollo de sus componentes principales.
